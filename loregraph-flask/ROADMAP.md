# LoreGraph — backlog

Что бы ещё имело смысл добавить поверх текущего состояния. Основное уже в коде и README.

## Уже реализовано

- Миры, категории, статьи, связи, граф (Cytoscape, force-layout).
- Автосейв (debounce 2с), версии (3 авто-слота + 2 ручных), теги (M2M), закладки (кросс-мировые).
- Полнотекстовый поиск через Postgres FTS — глобальный и локальный по миру.
- 8 пресетов сеттингов + кастомная тема (brand-цвет, display-шрифт).
- Обложки статей (16:9) и миров (3:1), аватары (1:1) с кроппером (Cropper.js + Pillow).
- Кастомные поля шаблона (`template_fields`) у категорий.
- Админ-панель: дашборд, пользователи (блок/анblock, ролевые операции), миры, append-only аудит-лог; все списки с пагинацией.
- Локальная сборка Tailwind через standalone-бинарь, production-запуск через waitress.
- CSRF, bcrypt, HTTPOnly/SameSite cookies, MAX_CONTENT_LENGTH, ротация логов.

## Что дальше

- **Экспорт мира в ZIP**: Markdown статей + JSON связей и метаданных + папка картинок. Импорт обратно — отдельная история.
- **Read-only шаринг по ссылке**: публичная страница мира/статьи без логина, с токеном.
- **Фильтр по тегам** в каталоге статей и в поиске.
- **Bulk-actions в админке**: групповая блокировка/удаление, фильтры по статусу/роли.
- **Тесты pytest**: storage (path traversal, ресайз), autosave (лимиты, чужие миры), version slots (rolling rotation).
- **Уведомления при создании связи на чужую статью** (если когда-нибудь появится co-editing).

## Сознательно не добавляем

- **Reset password по email**: нет SMTP/SES в проекте, упростит атакам — лучше через Google OAuth.
- **Светлая тема**: проект изначально дизайнился под тёмную, светлая ломает тематические декорации.
- **Co-editing статьи в реальном времени**: отдельная задача на полный SPA с WebSocket.
